# TiluxKeep

A Google Keep style notes application.

## About

TiluxKeep replicates the feel of Google Keep with cards, colors and quick note taking, built as a single page app.

## Features

- Card based notes
- Color coding
- Quick add and delete

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

Clone the repository and open the project in your browser or run it with your preferred local server.
